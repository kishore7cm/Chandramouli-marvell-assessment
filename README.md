https://www.kaggle.com/datasets/arnabbiswas1/microsoft-azure-predictive-maintenance

Expected files:
- data/PdM_telemetry.csv
- data/PdM_errors.csv
- data/PdM_failures.csv
- data/PdM_maint.csv
- data/PdM_machines.csv
